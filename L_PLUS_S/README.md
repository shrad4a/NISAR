
# L+S Dual Frequency Fusion

## Objective
Investigate whether combining NISAR L-band and S-band
radar observations improves water detection.

## Experiments
1. Repository and data compatibility audit
2. Spatial alignment
3. Decision-level fusion
4. Feature-level fusion
5. Confidence-aware fusion
6. Validation and comparison
7. Temporal water change detection

## Input Data
- L-band: ../L_BAND/
- S-band: ../S_BAND/

## Outputs
- Fused water masks
- Water probability maps
- Validation metrics
- Temporal change maps
